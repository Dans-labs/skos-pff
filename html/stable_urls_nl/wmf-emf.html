WMF staat voor Windows Metafile; EMF staat voor Enhanced Metafile. Deze bestanden sturen Windows aan om een afbeelding te tonen. Binnen Microsoft Office applicaties is het een standaardformaat voor vectorafbeeldingen.

De Metafile wordt beheerd door Microsoft en is geen open formaat. Buiten grote applicaties ondervindt het formaat geen goede ondersteuning. Het formaat berust op Windows en de specificering is niet stabiel.

Via software zoals Inkscape of Adobe Illustrator kunnen WMF en EMF bestanden naar het preferred format SVG geconverteerd worden.

WMF is een non-preferred format binnen bestandstype Afbeeldingen (vector).
