Cascading Style Sheets (CSS)

CSS is veelgebruikt op het web en wordt gebruikt om de opmaak van Markup Language documenten te definiëren. Voor duurzame archivering moet duidelijk zijn bij welke bestanden de CSS hoort en welke versie CSS is gebruikt. Ook moet bekend zijn wat de doelomgeving van de bestanden is, tenzij alleen de basiselementen worden gebruikt. Mocht de CSS referenties naar andere CSS-bestanden of externe bestanden bevatten, dan moeten deze links werken.

CSS is een preferred format binnen Opmaaktaal.
