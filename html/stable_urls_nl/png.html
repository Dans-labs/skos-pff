PNG (Portable Network Graphics) is een ISO standaard die wordt ondersteund door het World Wide Web Consortium (W3C).

PNG is bedoeld als vervanging voor het GIF-formaat. Naast een groot aantal andere functies biedt het formaat 32-bits kleurdiepte, bestandscompressie zonder kwaliteitsverlies en ondersteuning voor een Alpha-kanaal (transparantie). PNG ondersteunt geen standaard EXIF-metadata en omdat het formaat voornamelijk is ontworpen voor internetgebruik, ondersteunt het geen andere kleurruimten dan RGB.

PNG is een preferred format binnen bestandstype Afbeeldingen (raster).
