PNG (Portable Network Graphics) is an ISO standard that is supported by the World Wide Web Consortium (W3C).

PNG is intended as a replacement for the GIF format. In addition to a large number of other functions, the format offers 32-bit color depth, file compression without loss of quality and support for an Alpha channel (transparency). PNG does not support standard EXIF metadata and because the format is primarily designed for internet use, it does not support color spaces other than RGB.

PNG is a preferred format for file type Images (raster).
