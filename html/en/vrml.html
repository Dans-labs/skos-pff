VRML

VRML stands for Virtual Reality Modeling Language. It is a markup language for describing interactive 3D simulations, objects in networks and virtual worlds. The file format has the standard extension .wrl (world), but .vrml also occurs. The extensions .wrz and .wrl.gz are used when the format is compressed with gzip.

It is the predecessor of the X3D format and has since been replaced by X3D, which is why VRML is now considered a ‘legacy’ format.

VRML is a non-preferred format for file type 3D.
