Georeferenced images are raster images (TIFF, JPEG) provided with a means to read the image into Geographic Information Systems (GIS). The images are projected and scaled in a coordinate system.

Preferred formats 

  • GeoTIFF (.tif, .tiff)

Non-preferred 

  • TIFF World File (.tfw and .tif, possibly with additional files)
  • JPEG World File (.jgw and .jpg, possibly with additional files)
  • ERDAS IMAGINE File Format (.img)
