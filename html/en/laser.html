LASer

LAS is an open binary exchange format designed for LIDAR (LIght/Laser Imaging Detection And Ranging) point cloud data. The format is widely used and seen as a standard for lidar data. Outside of lidar, it can be used for any kind of 3-dimensional x/y/z data.

LAS was developed by the American Society for Photogrammetry and Remote Sensing (ASPRS) as an alternative to proprietary or to generic, slow-to-read ASCII files.
The file format LAZ is a lossless compression of LAS data originating from the open source project LASzip.

LAS and LAZ are preferred formats for file type 3D.
