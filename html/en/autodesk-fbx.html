Autodesk FBX

Autodesk FBX is a file format that is managed by the commercial Autodesk. It is not an open file format and support for the format outside of Autodesk applications is very limited.

FBX has been developed for interactive desktop applications. It offers little functionality for online applications and no support for “streaming”: the data is loaded as a whole.

Autodesk FBX is a non-preferred format for file type 3D.
