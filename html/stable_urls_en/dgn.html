DGN is a popular CAD format allied to the Bentley Systems ’MicroStation CAD software and Intergraph’s Interactive Graphics Design System. It is basically a competitive DWG format file, but in 2008, Autodesk and Bentley signed an agreement for the exchange of software libraries; this allows the mutual applications to read in each other’s formats.
Bentley supports the Open Design Alliance for the implementation of V8 DGN in the tools of the ODA.
However, support for the DGN format in other applications is very limited, in addition, it is not an open format.

DGN is a non-preferred format for file type Computer Aided Design (CAD).
