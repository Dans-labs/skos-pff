Encapsulated Postscript saves a vector image in the description language called postscript. The specification for this comes from Adobe and has been made publicly available.

Many applications support EPS, but the lack of a version number in the header data of a file can cause problems when opening the file in certain software.

EPS files can be converted to the preferred SVG format via software such as Inkscape or Adobe Illustrator.

EPS is a non-preferred format for file type Images (vector).
