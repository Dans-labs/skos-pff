Artec

A3D is raw data from the Artec 3D printer. It can only be opened with the Artec Studio software. The software can be used to export the 3D scans to other file formats, which are marked as preferred formats by DANS, such as OBJ and PLY.

Artec Studio .a3d is a non-preferred format for file type 3D.
