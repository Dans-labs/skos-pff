WaveFront Object

WaveFront Object is een zeer breed ondersteund open bestandsformaat voor de weergave van 3D geometrie. Het bestand bevat een heldere, simpele structuur waarin de ruimtelijke posities van elk punt van het object en textuurcoördinaten worden geschreven.

Het .obj bestand kan als ASCII tekstbestand of als binair formaat worden geleverd. ASCII OBJ heeft de voorkeur voor de toegankelijkheid en archivering op de lange termijn.

Naast het .obj bestand kan materiaal/textuur-informatie in een .mtl bestand worden opgeslagen. De textuur zelf wordt apart opgeslagen als een afbeelding. Lees meer over raster images.

OBJ slaat geen informatie over animaties op.

WaveFront Object is een preferred format binnen bestandstype 3D.
