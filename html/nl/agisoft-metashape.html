Agisoft Metashape

Agisoft Metashape is photogrammetry software that creates 3D models, point clouds and orthomosaic images. The software stores project information in its own XML file with extension .psx; the entire project archive is stored in a .psz file. The data cannot be opened with other software.

From the software, the 3D models can be exported to .ply files. For Agisoft Metashape files, this export is recommended for long-term archiving and reuse.

Agisoft Metashape is a non-preferred format for file type 3D.
