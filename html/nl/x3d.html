X3D

Het X3D formaat wordt beheerd door de non-profitorganisatie Web3D Consortium. Het is een op XML gebaseerde ISO standaard die is opgezet met het doel om de 3D standaard voor het web te worden.

Naast enkele 3D modellen is het formaat ook geschikt voor de opslag van complexe 3D data zoals virtual reality.

X3D bevat vrij uitgebreide ondersteuning voor de opslag van grafische elementen.

X3D is een preferred format binnen bestandstype 3D.
