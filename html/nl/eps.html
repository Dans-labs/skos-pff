Encapsulated Postscript slaat een vector-afbeelding op in de beschrijvingstaal genaamd postscript. De specificatie hiervoor is afkomstig van Adobe, deze is publiek beschikbaar gesteld.

Veel applicaties ondersteunen EPS, maar het ontbreken van een versienummer in de kopgegevens van een bestand kan problemen opleveren bij openen in bepaalde software.

Via software zoals Inkscape of Adobe Illustrator kunnen EPS bestanden naar het preferred format SVG geconverteerd worden.

EPS is een non-preferred format binnen bestandstype Afbeeldingen (vector).
